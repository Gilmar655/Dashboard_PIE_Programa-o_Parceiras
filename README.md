## GitHub Pages

Os arquivos index.html, styles.css, app.js, charts.js, excel.js, programacoes.js, programacoes.csv, enel-brasil-logo.png e favicon.svg devem permanecer na raiz da branch main.

A base programacoes.js é incorporada ao site. Cada pessoa acessa os dados sem importar o Excel. Existem filtros, indicadores, gráficos SVG, análise do comitê, ranking por contratada, relógio de São Paulo, tabela e exportações Excel/CSV.

Se o navegador usar dados antigos salvos localmente, clique em Restaurar. Para recarregar arquivos após publicação, pressione Ctrl+F5.

A soma de CHI por registro não equivale a clientes únicos afetados quando há projetos correlatos. A divulgação ocorre em repositório público, portanto valide autorização para publicar dados operacionais.
